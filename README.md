# Praktikum 5 — JavaScript Dasar dan Manipulasi HTML
 
### 1. Latihan 1 — Menampilkan Output

JavaScript digunakan untuk menampilkan teks "Hello World" pada halaman HTML dan Console browser.

**Hasil:** Teks Hello World tampil pada halaman dan Console.

### 2. Latihan 2 — Alert dan Prompt

Program meminta nama pengguna menggunakan `prompt()`. Jika nama diisi, program menampilkan sapaan menggunakan `alert()` dan mengubah teks pada halaman HTML.

**Hasil:** Program dapat menerima nama dan menampilkan pesan sesuai input.

### 3. Latihan 3 — Function dan Operasi Aritmetika

Program menggunakan function untuk melakukan operasi penjumlahan, pengurangan, perkalian, pembagian, dan modulus.

**Hasil:** Program menampilkan hasil perhitungan pada Console.

### 4. Latihan 4 — Percabangan If–Else

Program meminta pengguna memasukkan nilai antara 0 sampai 100. Nilai minimal 60 dinyatakan lulus, sedangkan nilai di bawah 60 dinyatakan belum lulus.

**Hasil:** Program dapat menentukan status kelulusan berdasarkan nilai yang dimasukkan.

### 5. Latihan 5 — Percabangan Switch

Program meminta pengguna memasukkan angka 1 sampai 5 dan menampilkan nama bilangan menggunakan `switch`.

**Hasil:** Program menampilkan nama bilangan sesuai pilihan pengguna.

### 6. Latihan 6 — Bilangan Genap atau Ganjil

Program menerima input bilangan bulat melalui form, kemudian menentukan apakah bilangan tersebut genap atau ganjil.

**Hasil:** Program dapat membedakan bilangan genap dan ganjil serta memvalidasi input.

### 7. Latihan 7 — Mengubah Warna Halaman

Program menyediakan tiga tombol untuk mengubah warna latar halaman menjadi hijau muda, putih, dan kuning muda.

**Hasil:** Warna latar halaman berubah sesuai tombol yang dipilih.

### 8. Latihan 8 — Checkbox Menu Makanan

Program menyediakan checkbox untuk memilih menu makanan dan menghitung total harga secara otomatis.

Daftar menu:
- Ayam goreng: Rp5.000
- Tempe: Rp500
- Telur dadar: Rp2.500

**Hasil:** Total harga berubah sesuai menu yang dipilih.
